CLIPAURA FOR IPHONE

Data Collection

ClipAura is a creative iOS video studio. Ordinary editing, captions, subject cutout, projects, and exports stay on your device. A private Firebase identity stores onboarding choices, and hosted AI receives media only after you approve the request.

Cloud profile

  • Firebase user identifier
  • Role, interests, style choices, and onboarding progress
  • Optional Apple display name and email address
  • Used only for app functionality and linked to the private account

Hosted AI, only with consent

  • Prompt and selected reference image or video frame
  • Model task identifier, status, and timestamps
  • Daily usage count used to return results and prevent abuse
  • Processed by Firebase and BytePlus Seedance 2.5

On device

  • Ordinary projects and exported videos
  • Timeline edits, captions, audio, Brand Kit, and settings
  • Photos library identifiers needed to reopen selected media
  • StoreKit entitlement state

Never collected by ClipAura

  • Full payment-card or bank details
  • Advertising identifiers or cross-app tracking data
  • Precise or coarse location
  • Contacts, health data, or browsing history

Service measurement

ClipAura stores hosted-AI task status and daily usage counts only to return results, resume pending work, and protect the service from abuse. It does not use this information for advertising or cross-app tracking.
